# 局域网歌词页（b_player，Windows）

把**当前曲目**的歌词页通过本机 HTTP 服务暴露给同一局域网内的浏览器，用于手机看词、
OBS/直播软件叠加等场景。与投放互不影响：投放走 CEF，这里走浏览器的 HTTP。

## 开关与地址

设置 → 广播 → **局域网歌词页**：

- 默认关闭，打开后 `0.0.0.0:<端口>` 开始监听，端口默认 `47622`（可改，1024–65535）。
- 面板按网卡列出可直接打开的地址，点「复制网址」带走。
- 不需要密码：同一网络内任何设备打开即可查看。只暴露正在播放的这一首，曲库不出本机。
- 手机与电脑需在同一网段；Windows 防火墙要放行该端口（首次监听时系统会弹窗）。

## 页面

- `GET /`：歌词页，背景**透明**，可直接作为 OBS 浏览器源叠加。
- `GET /?bg=dark`：恢复投放页的黑底/渐变背景，适合手机直接观看。
- 页面每 500ms 轮询一次状态；进度由页面按锚点自行推算，与轮询频率无关。
- 带 `逐字` 时间的行（如 KRC/QRC 歌词）按字扫光高亮，与投放页同一套渲染。
- 无曲目时页面底部显示「暂无播放内容」，避免纯透明/纯黑被误认为打不开。

### 每块屏的本地设置

同一个地址在不同设备/不同 OBS 源上可以各自调样式（行数、字号、颜色、对齐等），
互不影响：

- 打开面板：访问 `/?panel=1`，或在页面空白处**双击**。
- 设置存在该浏览器自己的 localStorage 里：OBS 的每个浏览器源、每台手机
  各有独立存储，改完即生效，应用重启、换曲目都保留。
- 「恢复跟随应用设置」清掉本屏覆盖，回到应用内的歌词素材设置。
- 同一浏览器里要调试多块屏：地址加 `?p=名字`（如 `/?panel=1&p=screenA`），
  每个名字一份独立设置；正式投放的 OBS 源里不需要带参数。

## 接口

| 路径 | 说明 |
|---|---|
| `GET /v1/state` | 当前曲目载荷：`style`、`lines`、`nowPlaying`、`tick`、`track`、`share` |
| `GET /fonts/<内置字体>` | 仅两套随包字体，供页面 `@font-face` 使用 |

`/v1/state` 与投放页 `window.enode.apply` 的 payload 同构，可直接给第三方渲染器复用：

- `style`：`castWebStyle()` 的输出，`showSeat` 固定 `false`。
- `lines`：`[行起点, 文本, 行尾, 逐字?]`，逐字是 `[起点, 终点, 文本]`。
- `tick`：`positionMs` + `wallMs` + `playing`，按 `positionMs + (now - wallMs)` 推算当前位置。
- `track`：`trackKey/title/artist/durationMs`，不含曲库索引。

## 边界

- 只接受 `GET`/`HEAD`，其余 405；未知路径 404。
- 只映射 `/`、`/v1/state`、`/fonts/*` 白名单，不做目录映射，路径穿越无效。
- 只读：没有写入、检索、入队入口；MQTT 协议不受影响。
- 应用退出时随 `AppState.dispose()` 关闭监听。

## 排障

- 日志标签 `[lyric-http]`：启动、端口占用、请求异常都会落盘。
- 端口被占时面板显示系统给出的原因，换一个端口点「应用」即可。
- 页面黑屏（`?bg=dark`）或全透明：先确认 `/v1/state` 里 `lines` 是否有内容、
  `nowPlaying.hasTrack` 是否为 `true`。
