# 屏幕投放（b_player，Windows）

投放是 B 端本地能力：不经 MQTT / 中继，协议文档不涉及。本文给部署与排障用，
说明通道结构、素材类型与已知约束。

## 通道结构

双通道，画布优先，一屏一窗兜底（`ENODE_CAST_LEGACY=1` 可强制旧通道排查）：

1. **画布通道（默认）**：一块 CEF OSR 画布纹理 + 每屏一个原生 presenter 窗。
   - 画布与页面布局用逻辑像素（与设置页预览同一套单位）；presenter 窗口坐标
     由 `monitor_rects.dart` 直接从 user32 取**物理像素**（rcMonitor / rcWork），
     任何缩放比例下位置正确，任务栏在顶部/底部的屏全屏也对齐。
   - CEF 运行时**一个进程只能初始化一次**：二次 initialize 必 INIT_FAILED 并带崩
     进程（0xc0000005）。运行时由插件析构函数收尾；浏览器生命周期归 Dart 层
     `disposeBrowser`，主窗口隐藏到托盘不会触碰运行时。
2. **一屏一窗（回退）**：每屏一个 Flutter 子引擎窗口。子进程缺少 CEF bootstrap
     runner，网页投放起不来时退自绘（只画歌词、无素材）。此回退是单向门，
     本次运行内不会自动升回画布（改设置可重试画布）。

## 素材类型

| 类型 | 说明 |
|---|---|
| `lyric` | 歌词叠层，样式全局共享，多屏天然同步 |
| `url` | 网页素材（iframe），可配刷新间隔 |
| `image` / `video` | 本地或 http 媒体，支持圆角、音量（仅 video） |
| `text` | 普通文字素材 |
| `idleText` | **闲时引导语**：仅在「无曲目在播且队列空」时显示，其余时间隐藏。与 `text` 共用排版字段，区别只在显隐由播放状态驱动 |

## 排障

- 日志标签 `[cast]`：投放计划、画布创建/销毁、通道回退原因都会落盘
  （应用支持目录 `logs/`，文件名按天滚动）。
- 画布失败的可读原因显示在设置页（含 NOT_READY / 缺 CEF 文件等）。
- 拔插显示器：8 秒一轮拓扑比对，变化自动重扫并按已存配置重投。
- 投放屏右键菜单：关闭本屏 / 全部关闭（素材与布局保留，重新勾选即恢复）。
